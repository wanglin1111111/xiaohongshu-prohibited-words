# 小红书违禁词合规自查技能

> 发文前的最后一道闸 —— 收录 72 个高频违禁词及合规替换方案

## 核心能力

- 🛡️ **72 词全表覆盖**：按首字分 6 类归档，逐词给出 ❌ 原文 → ✅ 替换建议
- 🔤 **子串匹配扫描**：支持 "最好的" → 命中 "最好" 这类派生形态
- 🧾 **逐处留痕**：每处替换都标注 `❌原文 → ✅替换`，不静默改写
- 📋 **分类输出报告**：按「绝 / 一 / 无 / 独 / 极·级 / 最」分组呈现，便于批量复核
- 🙋 **保留决策权**：技能只给建议，最终用哪个词由作者拍板

| 含「无」 | 11 | 无痕 → 不易察觉 / 无刺激 → 温和 / 无毒 → 无害 |
| 含「独」 | 11 | 独家 → 专有 / 独创 → 原创 / 唯独 → 尤其 |
| 含「极 / 级」 | 8 | 超级 → 特别 / 高级 → 高档 / 极强 → 强大 |
| 含「最」 | 19 | 最好 → 值得推荐 / 最低 → 优惠 / 最火 → 爆款 |
| **合计** | **72** | 来源：小红书社区规范整理 |

## 使用场景

- 撰写小红书帖子前的合规自查
- 已有草稿的敏感词批量排查
- 标题党、夸大宣传语气的降档改写
- 审核不通过 / 疑似限流后的复盘定位

## 工作流

1. 接收待检查文本（草稿 / 标题 / 正文）
2. 读取词典 `references/prohibited-words.md`
3. 逐词扫描，**不跳过任何匹配**（即使替换后语义略变）
4. 按分类输出替换建议，逐处标注原文对照
5. 可选：生成合规版本，并提示通读确认语义通顺
